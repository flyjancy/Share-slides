What an agent

不是更聪明的聊天机器人 —— 它多了三样东西

Pi Agent 介绍 · Fengrui
01 · 误区

Not a smarter chatbot

说起 Agent，大多数人的第一反应是「懂得更多的 ChatGPT」。但差别不在懂得多少，在能不能动手。

聊天机器人
你问它，它答你。
答完就结束了。
Agent
你交给它一件事，它自己拆步骤、
自己动手，直到做完。
聊天机器人输出文字，Agent 输出结果。
What an agent actually is
02 · 拆开看

A brain is not enough

01大脑会说话，会推理
02手能真的改动东西
03眼睛能看见自己改成了什么样
04记忆还记得刚才干了什么
聊天机器人只有大脑。
What an agent actually is
03 · Agent Loop

It can fix its own mistakes

想决定下一步做什么
▶
动手用手去改东西
▶
看结果看改成了什么样
带着结果回去，重新想
聊天机器人没有这个 Loop —— 它只会说抱歉。
What an agent actually is
04 · 能力的边界

Its limits are its hands

它能做什么，完全取决于你给了它几只手。

01遇到「它做不了」，第一个该问的不是「它够不够聪明」，是「它有那只手吗」。
02给 Agent 加能力，本质上就是给它装一只新手。
它做不到，往往不是笨，是没有那只手。

05 · 一个例子

Pi gets by with four hands

01读read把文件内容读进来
02写write新建一个文件
03改edit精确改动已有的文件
04跑命令bash在电脑上执行命令 —— 什么都能干
一个万能后门，胜过一百个专用工具。

06 · 设计哲学

Why it dares to be this small

01不做计划模块、不做任务清单、不做多 Agent 调度。
02理由很简单：它不该替你决定你怎么干活。
03不预装不等于做不到 —— 位置留出来，是给你自己的规矩的。
它给的是原料，不是成品。
What an agent actually is
07 · 为什么「小」是优点

You can read it, so you can trust it

01功能少  →  你能看懂它在干嘛
02你看得懂  →  你敢让它干活
03你告诉它「我习惯这么干」，下次它还记得 —— 不用每次重新交代
代价也要说清楚：很多东西得自己配，没有现成的省心流程。
信任来自看得懂，不来自功能多。
What an agent actually is
08 · 它的短板

It forgets

01干得越久，越容易忘掉开头说过的话。
02记忆（context）装满了就得压缩，压缩会丢掉细节。
03所以你可以：中途插话纠正它，或者回到过去某一步重新开始。
它记不住的不是你，是它自己刚做过的事。
