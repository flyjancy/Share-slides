## 放映

用浏览器打开任一 HTML 即可放映。字体与图片全部内嵌，无需网络。

- `→` / `空格` / `Enter` / 鼠标点击：下一页
- `←`：上一页 · `Home` / `End`：跳到首尾
- `f` 全屏 · `s` 讲者备注 · `p` 打印导出 PDF · `?` 快捷键帮助

## 讲稿

每份 `讲稿.md` 逐页给三样：**标题意思**（英文标题的人话）、**讲**（可直接照念的话）、**停 / 动作**（节奏与互动提示）。开头附标题对照表，结尾有预设问答与「讲的时候不要做的三件事」。它是 deck 内置备注（放映时按 `s` 显示）的展开版，两处不一致时以讲稿为准。
